## 1. Baseline: playable game, five content packs

**What**
- Vite + vanilla TypeScript app with no UI framework, built to static files.
- The canvas pixel-art scene (`src/render/scene.ts`) has a torch-lit shaft, a bonfire with a
  coiled sword, ash/ember particles, banded pixel lighting, a knight that sinks
  as you score, and red eyes deeper down.
- Synthesized WebAudio sound effects (`src/render/sfx.ts`).
- Screens:
  - home (bonfire)
  - Daily Descent
  - Themed Catacombs (4 themes + 3 sealed)
  - Archive (practice)
  - game
  - results with emoji share
  - how-to-play and settings modals
- i18n for EN, PL and UK, auto-detected and switchable.
- The answer engine (`src/engine/normalize.ts`, `match.ts`):
  - Cyrillic transliteration, diacritic stripping and phonetic folding
  - Roman numerals, typo tolerance by length, and a per-prompt reject list
  - exact spelling takes priority, which keeps кіт (cat) and кит (whale) apart
- Daily deal: a weighted rotation across packs with seeded per-pack decks, so no repeat
  within 9 days. A run in progress is pinned to its prompt ids, and reloading
  counts the current prompt as lost.
- Content written by agents and checked by `npm run validate`:

## 2. Difficulty tags on every prompt + content guide

**What**
- New required field `d: 1 | 2 | 3` (easy/medium/hard) on `PromptSpec`. It measures
  how hard it is to name *any* valid answer for a general player.
- All 144 existing prompts are tagged by hand (`scripts/tag-difficulty.py`, kept for
  reference). Split: 50 easy / 74 medium / 20 hard, so new content should lean
  toward hard.
- The geography country prompts are generated by `countries()`, so their tags live in
  `COUNTRY_DIFFICULTY`.
- The validator now requires `d` and warns when a question is longer than 60 characters.
- `docs/content-guide.md` is the single brief for anyone (human or agent) writing
  packs: schema, tiers, difficulty, wording rules, validation.

**Verified:** the validator reports 0 errors and `tsc` is clean.

## 3. Difficulty in play: easy → hard descent, skull badges

**What**
- `byDifficulty()` (stable sort) orders every run's seven prompts from easy to
  hard. This covers the Daily Descent (after the seeded deal) and themed runs.
  The descent literally gets harder as the knight sinks.
- Each prompt shows 1–3 pixel skulls plus a depth name beside the counter:
  Shallow / Deep / Abyssal (PL Płytko / Głęboko / Otchłań, UK Мілко / Глибоко / Безодня).
  Abyssal skulls glow red.
- The How-to-play rules mention the rising difficulty in all three languages.

**Verified:** `tsc` and the build are clean. A daily screenshot shows the badge, and prompt 1 is a Shallow one.
